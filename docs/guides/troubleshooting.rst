===========================
Troubleshooting
===========================

Problèmes courants
------------------
- ❌ Accès refusé  
  → Vérifier les privilèges admin

- ❌ Script bloqué  
  → ``Set-ExecutionPolicy RemoteSigned``

- ❌ TrustedInstaller introuvable  
  → Vérifier que Windows Modules Installer est actif
