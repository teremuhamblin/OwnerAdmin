===============================
Notes de Design
===============================

Objectif
========
Documenter les choix de design, le style visuel et les conventions
militaires Ghost Recon appliquées au projet.

Style Visuel
============
* ASCII Banner  
* Interface Ghost Recon  
* Couleurs tactiques (vert, cyan, gris)  

Normes
======
* Documentation en ``.rst``  
* Structure Sphinx  
* Terminologie ACL / SDDL  

Philosophie
===========
* Sécurité avant fonctionnalité  
* Transparence des actions  
* Restauration systématique de l’état initial
